# Админ-панель транскрибатора

Локальный дашборд: подключается по SSH к серверу с транскрибатором, показывает
нагрузку (recharts-графики с историей), архив задач с результатами и
интерактивный терминал. Запускается одной командой на твоей машине.

## Как работает
- **Серверная часть** (сборщик метрик) — отдельный контейнер `collector` в
  `docker-compose` транскрибатора. Постоянно пишет CPU/RAM/диск + события задач
  в SQLite (`data/metrics.db` на `/srv`). История копится всегда, переживает
  перезагрузку.
- **Эта панель** — локальный бэкенд (FastAPI + paramiko) + фронтенд (React +
  recharts + xterm). По SSH тянет историю и живые данные, не требует ничего
  ставить на сервер сверх контейнера.

## Шаг 1 — обновить сервер (разово, чтобы появился сборщик)
В пакете транскрибатора уже добавлены сборщик и том `data`. Перезалей пакет и
пересобери на сервере:
```bash
# с локальной машины
cd ../deploy && ./deploy.sh <ip> <username>
# на сервере
cd /srv/transcriber && docker compose up -d --build
```
Проверь, что сборщик поднялся: `docker compose logs collector` → `[collector] старт`.

## Шаг 2 — запустить панель
```bash
cd admin
./admin.sh <ip> <username>        # пароль спросит
```
Откроется `http://localhost:8765`.

Требования локально: `python3` и `Node/npm` (фронтенд собирается один раз).

## Разделы
- **Нагрузка** — CPU/RAM/load во времени (выбор диапазона 15м…24ч), занятость дисков.
- **Задачи** — график «аудио vs обработка», таблица-архив, клик → просмотр разбора и скачивание JSON.
- **Терминал** — настоящий shell на сервере (top, htop, docker logs работают).

## Настройка
- Порт панели: `ADMIN_PORT=9000 ./admin.sh ...`
- Имя контейнера (если проект назван иначе): `SRV_CONTAINER=... ./admin.sh ...`
  (по умолчанию `transcriber-transcriber-1`).
